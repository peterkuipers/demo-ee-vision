# demo-ee-vision

**The author's own vision, in its raw carriers.** Presentations, sketches, whiteboard photographs,
notes, recordings — the material that `demo-ee-skills:docs/vision.md` records the *conclusions* of.

**This repository is level 3 of the source hierarchy, and nothing in it is a source.** It may be
applied only where a higher source is unclear, self-contradictory or demonstrably wrong, and never
against the literature. Read `CLAUDE.md` before using anything here; the rule there is absolute and it
is what makes this repository safe to have.

| repository | hierarchy level | holds |
|---|---|---|
| [`demo-ee-sources`](https://github.com/peterkuipers/demo-ee-sources) | 1–2 — standards and the books | the literature: EO2, DEMOSL, published academic work |
| [`demo-ee-skills`](https://github.com/peterkuipers/demo-ee-skills) | — the method | the skills, `sources/` extracts, the meta-model |
| [`demo-ee-cases`](https://github.com/peterkuipers/demo-ee-cases) | — the evidence | cases, runs, the engine, the Console |
| **`demo-ee-vision`** | **3 — own vision** | **this repository: the carriers** |

**Private**, like every repository in this set. The material carries client and employer content — but
that is not why it is a repository of its own: **standing and kind** are.
